# Electrical Interfaces and Connector Control

**Status:** Requirements; pin assignments and voltage levels remain TBD.

Interface categories: dendritic inputs/states, six soma channels, membrane/threshold, spike/axon outputs, synaptic conductance/update, neuromodulation buses, regional interconnect, sensor front ends, motor command/proprioception, power and safety.

Before assigning a connector, specify for every pin: signal name, direction, class, minimum/nominal/maximum voltage, current limit, impedance, reference/return, protection, default state and connector keying. Include physical pin numbering and revision.

Connector changes require a revision and compatibility note. Physical fit does not imply electrical compatibility.
