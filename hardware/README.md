# Hardware Development

Every released board must include editable sources, fabrication outputs, BOM, assembly notes, revision, test points, safety notes and validation evidence.

- `neuron_n1/` — complete custom physical neuron.
- `synapses/` — E/I synapses and plasticity.
- `neuromodulation/` — analogue modulation.
- `connectome_boards/` — regional interconnect/backplane.
- `sensory_boards/` — analogue sensor front ends.
- `motor_control/` — motor interfaces and drivers.
- `power_management/` — rails, protection and safety.

No board is build-ready until its schematic, electrical limits and BOM have been reviewed.
